# 📊 Sales Performance Dashboard (Excel)

An interactive Excel dashboard built to analyze 500+ sales transactions across 4 regions and multiple product categories — using PivotTables and PivotCharts to surface revenue trends and top-performing items. Built end-to-end in 20 minutes.

## 🎯 Objective

Turn raw, unstructured sales data into clear, decision-ready insights — identifying which regions and products drive the most revenue.

## 📁 Dataset

The dataset (`0_Data (2).xlsx`) contains 500 sales transaction records with the following fields:

| Column | Description |
|---|---|
| Sl No | Transaction serial number |
| Date | Date of sale |
| Customer | Customer name |
| Region | North / South / East / West |
| Item | Product sold (USB Drive, Charger, Pen Set, Chair, Desk Lamp, etc.) |
| Qty | Quantity sold |
| Price | Unit price |
| Amount | Total transaction value (Qty × Price) |

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts

## 🔍 What I Did

1. Structured and cleaned the raw sales data for analysis
2. Built PivotTables to summarize revenue by **Region** and by **Product/Item**
3. Created PivotCharts to visualize:
   - Revenue distribution across regions
   - Top-performing products by sales
4. Compiled the above into a single-view dashboard for quick business insights

## 📈 Key Insights

- Revenue breakdown across all 4 regions, highlighting the top-performing region
- Top-selling products by revenue and quantity
- Clear region-vs-product view for spotting sales patterns at a glance
